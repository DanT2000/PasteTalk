# PasteTalk Server

Позволяет диктовать с телефона и из Telegram, пользуясь домашним компьютером с
PasteTalk. Когда компьютер выключен — уходит в облако, чтобы человек не остался
перед пустым экраном.

## Чего здесь нет

**Ни звука, ни распознанного текста сервер не хранит.** В базе только счётчики:
кто, когда, сколько секунд, где считали и во сколько обошлось. Владелец видит,
сколько человек надиктовал, но не видит, что именно.

Это не обещание на словах: в таблице `usage` просто нет столбцов, куда можно
было бы это положить.

## Как устроено

```
Telegram ─┐
          ├─HTTPS─> этот сервер ─┬─ ПК на связи? ─> WebSocket ─> PasteTalk дома
Android ──┘                      └─ нет ─────────> облачный провайдер
```

Соединение с домашним компьютером всегда исходящее: звонит он, а не сервер.
Ничего пробрасывать на роутере не нужно, работает из-под любого NAT, и наружу
не открывается ни один порт с распознаванием.

## Развернуть в Coolify

1. Новый ресурс → **Dockerfile**, репозиторий `DanT2000/PasteTalk`.
2. **Base Directory:** `/` — сборка идёт из корня, иначе в образ не попадёт
   папка `shared/` с общими промптами.
3. **Dockerfile Location:** `server/Dockerfile`
4. **Port:** `3000`
5. **Volume:** любое имя → путь в контейнере `/data`. Без тома счётчики
   пропадут при первой же пересборке.
6. Домен — свой, обязательно с HTTPS: по сети ходят коды доступа и токены.

## Развернуть руками

```bash
docker build -f server/Dockerfile -t pastetalk-server .
docker run -d --name pastetalk -p 3000:3000 -v pastetalk-data:/data pastetalk-server
curl http://localhost:3000/health   # {"ok":true}
```

## Первый вход

Откройте `/admin/`. **Заводского пароля нет.** Панель встретит вас формой
«придумайте пароль» — первый введённый и станет настоящим.

Сделайте это сразу после развёртывания: пока панель не занята, занять её может
любой, кто знает адрес. Сервер об этом кричит в журнал при каждом запуске.

Забыли пароль или панель занял кто-то раньше вас — задайте контейнеру
`PASTETALK_RESET_PASSWORD=1`, запустите один раз и придумайте новый.

Дальше:

1. **Настройки** — впишите ключ AITunnel (или OpenAI, DeepSeek) и проверьте
   цепочки. В цепочке распознавания DeepSeek не работает: речь он не умеет,
   только текст.
2. **Люди** — «Выдать код», задайте имя. Получите шесть цифр.
3. На компьютере: PasteTalk → **Настройки → Интеграция** → адрес сервера
   (`wss://ваш-домен`) → введите код → «Привязать».
4. **ПК** — убедитесь, что появилось «На связи».

## Telegram-бот

Живёт внутри этого же процесса — отдельного контейнера не нужно. Впишите токен
от [@BotFather](https://t.me/BotFather) в **Настройки → Токен Telegram-бота**, и
бот начнёт отвечать сразу, без перезапуска сервера. Пустой токен — бот молчит.

Бот умеет ровно три вещи:

| Человек | Бот |
|---|---|
| Прислал голосовое | «Распознаю…» превращается в текст с двумя кнопками |
| Нажал кнопку | Текст заменяется причёсанным |
| Написал `/id` | Отвечает его номером в Telegram |

Отвечает он **только внесённым**. Незнакомец получает «нужен код доступа» — и
ничего больше не происходит, денег это не стоит. Чтобы привязаться, человек
присылает боту те же шесть цифр, что и для телефона.

Команда `/id` работает у всех без исключения, даже у непривязанных: иначе вам
неоткуда было бы взять номер для ручной привязки в разделе «Люди».

Сообщения бот забирает длинными опросами, а не вебхуком, — Telegram никуда не
стучится, и менять домен можно свободно.

## Расход

Цифра в разделе «Расход» — **оценка по своему прайсу, а не факт от провайдера.**
AITunnel объявляет заголовки `cost-rub` и `balance`, но фактически их не
присылает: ни в ответе, ни отдельной ручкой. Поэтому цены лежат в настройках
(₽ за минуту звука и ₽ за миллион токенов), а сервер умножает сам. Когда
провайдер меняет цены, прайс правится руками.

Сделанное домашним компьютером стоит ноль — своя видеокарта денег не берёт.

## Доступ

Ключ — это профиль с именем, код — **разовый пропуск** к нему. Ввели — код
исчез, устройство привязано, дальше оно ходит по токену. Подсмотренный или
пересланный код ничего не откроет.

Код живёт заданное время: по умолчанию десять минут, при выдаче можно выбрать
до суток. Не успели — кнопка «новый код»; уже привязанные устройства этого не
замечают.

Одно устройство — один профиль: «Мама, телефон» и «Мама, телеграм». Так видно,
откуда пришёл доступ, и лишний убирается отдельно.

Три неверных попытки подряд запирают источник на десять минут — иначе шесть
цифр перебираются за вечер. Просроченный код промахом не считается: опоздавший
не взломщик.

## Настройки окружения

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `PORT` | `3000` | Какой порт слушать |
| `PASTETALK_DB` | `рядом с сервером` | Где лежит база со счётчиками |
| `TRUSTED_PROXIES` | `1` | Сколько прокси перед сервером |
| `TZ` | `UTC` | Часовой пояс для «за месяц» и графика |
| `PASTETALK_RESET_PASSWORD` | — | `1` сбрасывает пароль панели при запуске |

## Разработка

```bash
cd server
npm install
npm test     # node --test, без сторонних фреймворков
npm start
```

`npm test` без аргументов — не `node --test test/`: на Windows Node принимает
папку за модуль и падает с `MODULE_NOT_FOUND`.

## Сколько прокси перед сервером

`X-Forwarded-For` — список, который дописывается по дороге, и первый в нём
пишет **сам клиент**. Верить ему нельзя: подставив там `192.168.1.5`, чужой
человек выдал бы себя за домашнюю сеть. Поэтому сервер отсчитывает адрес с
конца — от записи, которую добавил ближайший доверенный прокси.

Сколько их у вас, знаете только вы:

| Как развёрнуто | `TRUSTED_PROXIES` |
|---|---|
| Coolify (Traefik) напрямую | `1` — по умолчанию |
| Своё что-то перед Coolify (nginx, openresty) | `2` |
| Совсем без прокси | `0` |

Ошибётесь в меньшую сторону — заводской пароль `admin` будет приниматься из
интернета до первой смены. В большую — все запросы сочтутся пришедшими из
локальной сети, и запреты по адресу перестанут различать людей.

## Часовой пояс

Месяц и сутки считаются по времени сервера. В контейнере это UTC, поэтому
владельцу в UTC+3 стоит задать `TZ=Europe/Moscow` — иначе первого числа
первые три часа он будет видеть итог прошлого месяца, а ночные диктовки
лягут в столбик предыдущего дня.
