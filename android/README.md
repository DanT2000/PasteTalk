# PasteTalk для Android

Одна большая кнопка: нажал, сказал, получил текст. Распознаёт всё тот же
домашний компьютер через [сервер](../server/README.md), а когда он выключен —
облако.

## Для кого

Приложение делалось для человека, который **плохо видит**. Отсюда крупный шрифт
с самого начала, кнопка записи в треть экрана и проверка при системном шрифте
200 % — а не «можно увеличить в настройках».

## Что умеет

1. Нажал большую кнопку → говорит → нажал снова → получил текст.
2. Текст сразу оказывается в буфере обмена — как на компьютере.
3. Захотел причесать — две кнопки под текстом: «Почистить» и
   «Почистить и переписать». Те же названия, что на компьютере и в боте.

Чего нет намеренно: файлов, истории, выбора модели и языка, настроек
распознавания. Всё это живёт в админке. Телефон — для голоса.

## Собрать

Нужны JDK 17 и Android SDK (platform 35).

```bash
cd android
echo "sdk.dir=/путь/к/Android/Sdk" > local.properties
./gradlew :app:assembleDebug
```

APK окажется в `app/build/outputs/apk/debug/`.

## Подключить

1. Возьмите шестизначный код в админке сервера.
2. Откройте приложение, впишите адрес сервера и код.
3. Всё. Тот же код работает и в Telegram-боте: один ключ, разные устройства.

Отозвали ключ в админке — приложение при следующем обращении вернётся на экран
подключения. Молча перестать работать оно не должно.

## Из чего собрано

Kotlin и Jetpack Compose, `minSdk 26`, `compileSdk 35`. **Сторонних библиотек
нет:** сеть — `HttpURLConnection`, разбор JSON — `org.json`, запись — 
`MediaRecorder`. Всё это уже в Android, а каждая лишняя зависимость — лишний
повод сборке сломаться через год.

Звук пишется в M4A (AAC), 16 кГц, моно: Whisper этого хватает с запасом, а
минута занимает около 120 КБ.

## Про безопасность

Обычный HTTP запрещён: по сети ходят коды доступа, токены и надиктованный
текст. Исключение сделано только для `10.0.2.2` — так эмулятор видит компьютер
разработчика. На настоящих телефонах такого адреса нет.

## Разрешения

Одно спрашивается у человека — запись звука, и в тот момент, когда он первый раз
жмёт кнопку, а не при запуске. Интернет выдаётся при установке молча, но
объявлен в манифесте: без этого любой запрос падает с `EPERM`.
