# PasteTalk

**Голос в текст по горячей клавише. Локально, без интернета.**

Нажали → сказали → нажали ещё раз → текст в буфере обмена.
Распознавание идёт на вашем компьютере: ни звук, ни текст никуда не уходят.

## 📥 Установка

1. Скачайте **`PasteTalk-x.y.z-Setup.exe`** со [страницы релизов](https://github.com/DanT2000/PasteTalk/releases/latest).
2. Запустите. Windows покажет синее окно «SmartScreen защитил ваш компьютер» — это потому, что установщик не подписан платным сертификатом, а не потому, что с ним что-то не так. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Выберите папку, поставьте галочку ярлыка на рабочем столе — и всё.
4. При первом запуске программа спросит модель и микрофон и скачает модель. Это разово: **Large-v3 весит 3 ГБ**, дальше интернет не нужен.

Значок появится **рядом с часами** — там же настройки, пауза и выход.

## 🎙 Как этим пользоваться

| | |
|---|---|
| **Начать и закончить запись** | `Ctrl` + `Alt` + `Space` |
| **Закончить и сразу улучшить текст** | `Ctrl` + `Alt` + `Enter` |
| **Улучшить то, что уже в буфере** | `Ctrl` + `Alt` + `I` |
| **Быстрые параметры на лету** | `Ctrl` + `Alt` + `Q` (пока держите) |

Сочетания меняются в настройках — нажмите «Изменить», нужные клавиши и `Enter`.

Внизу экрана появляется небольшая панель поверх всех окон: слева настройки, в центре микрофон, справа кнопка ИИ. Полоски по бокам показывают настоящую громкость — молчите, ниточка; говорите, столбики.

**Текст не ждёт конца речи.** Запись режется по паузам: закончили фразу — она уже ушла в модель, пока вы говорите дальше.

## ✨ Что умеет

- **Распознавание на своём железе** — [faster-whisper](https://github.com/SYSTRAN/faster-whisper) на видеокарте (CUDA) или процессоре. Пять моделей от Tiny до Large-v3, переключаются в настройках.
- **Текст сразу в дело** — ложится в буфер обмена и, если попросить, вставляется сам нажатием `Ctrl`+`V`.
- **Улучшение текста** — языковая модель убирает слова-паразиты и приводит сказанное в порядок. Обычный текст при этом уже у вас: улучшенный приходит следом и заменяет его, а если модель не ответила — терять нечего.
- **Расшифровка файлов** — видео и аудио, с метками времени или без. Модель для файлов можно взять другую, чем для диктовки.
- **Размер интерфейса 100 / 125 / 150 %** — всё окно целиком, включая панель записи. Сделано для тех, кому мелкий шрифт читать тяжело.
- **Защита от случайного нажатия** — если вы так ничего и не сказали, запись отменяется молча и в буфер ничего не кладётся.
- **Присмотр за собой** — движок распознавания перезапускается сам, а если не поднялся с трёх попыток, программа скажет об этом, а не промолчит.

## 🤖 Улучшение текста: откуда брать модель

Работает поверх готового текста и **выключено по умолчанию**. Любой вариант на выбор:

| Откуда | Ключ | Заметки |
|---|---|---|
| **LM Studio** | не нужен | Включите в нём локальный сервер. Для чистки речи хватает модели уровня Gemma 3 4B и выше — задача простая |
| **Ollama** | не нужен | `ollama pull` нужной модели |
| **Claude Code** | не нужен | Идёт через вашу подписку. Модель на выбор: Haiku `$`, Sonnet `$$`, Opus `$$$` |
| **Codex** | не нужен | Идёт через вашу подписку. Модель на выбор: `gpt-5.6-luna`, `terra`, `sol` |
| **ChatGPT, DeepSeek** | нужен | Обычный ключ OpenAI-совместимого API |
| **Своё** | по обстоятельствам | Любой сервер с `/v1/chat/completions` |

Модель полегче отвечает быстрее и стоит дешевле — для расстановки запятых самая мощная не нужна.

> **Про «думающие» модели.** Если модель умеет рассуждать, PasteTalk просит её этого не делать. Разница ощутимая: на очистке одной фразы Gemma 4 12B тратила 26 секунд и 694 токена рассуждений, а с выключенными — секунду и 17 токенов при том же результате.

## 🎬 Расшифровка файлов

Перетащите видео или аудио в раздел «Файлы». Поддерживаются MP4, MKV, MOV, WEBM, MP3, WAV, M4A, OGG, FLAC.

<a name="ffmpeg"></a>**Для видео нужен FFmpeg** — он достаёт звуковую дорожку. Программа проверяет его сама и пишет, найден он или нет. Поставить:

```powershell
winget install Gyan.FFmpeg
```

После установки перезапустите PasteTalk. Без FFmpeg читаются только аудиофайлы.

## 🔒 Что уходит в интернет

Ничего, кроме одной вещи: **при первом запуске скачивается модель** с Hugging Face. Дальше распознавание идёт полностью на вашем компьютере — записи и тексты никуда не отправляются и нигде не хранятся, кроме буфера обмена.

Единственное исключение — **улучшение текста через облачного провайдера** (ChatGPT, DeepSeek, платный шлюз). Тогда готовый текст уходит туда, куда вы его направили. С LM Studio, Ollama, Claude Code и Codex всё остаётся на машине или идёт через вашу личную подписку.

Ключи доступа лежат только у вас, в `%APPDATA%\pastetalk\settings.json`.

## 🛠 Собрать самому

Нужны [Node.js 20+](https://nodejs.org/) и [uv](https://docs.astral.sh/uv/) — Python устанавливать не надо, uv принесёт нужную версию сам и системный не тронет.

```powershell
winget install OpenJS.NodeJS.LTS
winget install astral-sh.uv

git clone https://github.com/DanT2000/PasteTalk.git
cd PasteTalk

npm install              # зависимости приложения
npm run engine:setup     # Python 3.12 + faster-whisper в engine/.venv
npm start                # запустить
```

Собрать установщик:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/make-icon.ps1   # иконки
npm run engine:build                                             # движок в один exe
npm run build                                                    # release/PasteTalk-x.y.z-Setup.exe
```

### Как всё устроено

```
app/main/       основной процесс: трей, горячие клавиши, буфер обмена, присмотр
app/renderer/   окна: настройки, панель записи, скрытый захват звука
engine/         движок распознавания на Python — отдельный процесс
design/         макеты, с которых всё начиналось
```

Движок — отдельный процесс намеренно: упавшая модель не роняет интерфейс, а тяжёлая CUDA живёт своей жизнью. Общаются по HTTP на случайном порту localhost с одноразовым токеном; когда приложение закрывается, движок это замечает по закрытому stdin и уходит следом.
